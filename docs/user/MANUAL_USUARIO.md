# Manual de usuario

Este manual explica cómo jugar a Crash Circuit. Se ampliará a medida que se terminen las entregas.

## Qué puedes hacer ahora

Por ahora el juego solo muestra una escena 3D de prueba a pantalla completa. Si cambias el tamaño de la ventana, la escena se adapta.

Todavía no hay menú, selección de coche o circuito, controles de conducción, carrera, puntuación ni resultados. Se irán añadiendo en las próximas entregas.

Para abrir el juego, mira el [README](../../README.md).
